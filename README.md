# Gantt Manager

## Description
A Java-based application for managing and visualizing project timelines using Gantt charts.

## Features
- Create and manage tasks
- Define start and end dates
- Visualize project timelines
- Simple and structured task management

## Technologies
- Java

## How to Run
1. Compile the project
2. Run main class

##  Example Use Case
This tool can be used to organize project tasks and visualize deadlines in a clear timeline format.
